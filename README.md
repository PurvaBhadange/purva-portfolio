# Purva Bhadange - Portfolio

Portfolio landing page for Purva Manishrao Bhadange — AI/ML & Full-Stack Engineer featuring interactive living portrait, project showcases, and contact system.
</div>

## Tech Stack

- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Motion, Lucide React
- **Backend / API:** Node.js, Express, tsx
- **Build Tool:** Vite 8

## Getting Started Locally

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/PurvaBhadange/purva-portfolio.git
   cd purva-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables (optional):
   ```bash
   cp .env.example .env
   ```
   Set `GEMINI_API_KEY` (if using Gemini features), and optional contact endpoint variables (`FORMSPREE_ENDPOINT` or `WEB3FORMS_ACCESS_KEY`).

4. Run development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
